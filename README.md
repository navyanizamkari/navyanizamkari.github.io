## 🚀 Quick Setup for GitHub Pages

1. **Fork or Clone this repository**
   ```bash
   git clone https://github.com/yourusername/navya-portfolio.git
   cd navya-portfolio
   ```

2. **Customize the content**
   - Update [`index.html`](index.html) with your personal information
   - Replace placeholder links with your actual social media profiles
   - Add your profile photo to the `images/` directory
   - Update contact information and resume details

3. **Enable GitHub Pages**
   - Go to your repository settings
   - Scroll down to "Pages" section
   - Select "Deploy from a branch"
   - Choose "main" branch and "/ (root)" folder
   - Save the settings

4. **Your website will be live at**: `https://yourusername.github.io/repository-name`

## 🎨 Customization Guide

### Adding Your Profile Photo
1. Add your profile photo to the `images/` directory
2. Update the hero section in [`index.html`](index.html):
   ```html
   <div class="profile-placeholder">
       <img src="images/your-photo.jpg" alt="Navya Sri Nizamkari" />
   </div>
   ```

### Updating Social Links
Replace the placeholder links in the navigation and footer:
- LinkedIn: Update `href="https://linkedin.com/in/your-profile"`
- GitHub: Update `href="https://github.com/yourusername"`
- Email: Update `href="mailto:your-email@domain.com"`

### Customizing Colors
The main color scheme can be updated in [`css/style.css`](css/style.css):
- Primary Blue: `#2563eb`
- Accent Orange: `#fbbf24`
- Dark Gray: `#1f2937`

### Adding Blog Posts
1. Create new HTML files in the `blog/` directory
2. Follow the structure of the existing blog template
3. Update the blog index page to link to new posts

## 🔧 Local Development

To run this website locally:

1. Clone the repository
2. Open `index.html` in your web browser
3. Or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server
   
   # Using PHP
   php -S localhost:8000
   ```
